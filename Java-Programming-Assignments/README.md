# Java Programming Assignments

A collection of Java programming assignments and practice programs.

## Repository Structure

- `Assignments/` — Submitted programming assignments, organized by assignment number.
- `Practice/` — Additional Java practice programs.

## How to use

1. Open the relevant `Assignment-XX` folder.
2. Add your Java source files (for example, `Main.java`).
3. Add a short `README.md` describing the problem and approach when useful.
4. Commit and push your changes to GitHub.

## Compile and run

```bash
javac Main.java
java Main
```
